# Workshops

```{admonition} This page has moved!
:class: important

Workshops about napari now live on the
[napari workshops site](https://napari.org/workshops/).

- For current workshop materials managed by the napari team, see the
  [workshop catalogue](https://napari.org/workshops/).
- For a listing of past workshops, see
  [Past workshops](https://napari.org/workshops/past-workshops/).
- For a listing of upcoming workshops, see
  [Events](https://napari.org/workshops/events/).
- For help developing your own workshop, see the
  [organizer guide](https://napari.org/workshops/instructors/organizers/) and
  [instructor guide](https://napari.org/workshops/instructors/instructors/).
```

Have you taught, or are you planning, a workshop about napari? We would love
to list it! Open a pull request to the
[napari/workshops repository](https://github.com/napari/workshops), or contact
the core team on [Zulip](https://napari.zulipchat.com/).

You can find more videos of talks, tutorials and demos on the
[napari YouTube channel](https://www.youtube.com/channel/UCbTgw84ew4pxTJ9qu3W2hqg/playlists).
