napari 0.10.0#

Fri, Oct 30, 2026

We’re happy to announce the release of napari 0.10.0! napari is a fast, interactive, multi-dimensional image viewer for Python. It’s designed for browsing, annotating, and analyzing large multi-dimensional images. It’s built on top of Qt (for the GUI), vispy (for performant GPU-based rendering), and the scientific Python stack (numpy, scipy).

For more information, examples, and documentation, please visit our website, https://napari.org.

napari follows EffVer (Intended Effort Versioning); this is a Macro release containing awesome new features, but may require dedication of some significant time when upgrading projects to use this version.

Highlights#

This release contains several new features and many enhancements and bugfixes. We also welcomed a ton of new contributors to the community!

Coordinate Grid with axes and ticks#

This features has been requested for years, and we finally managed to get a version that we’re happy with! With #7827, you can now use viewer.scene.overlays.coordinate_grid to display a grid on your data, including unit-aware tick marks and axis labels! Try it out:

import napari

viewer = napari.Viewer(ndisplay=3)
layers = viewer.open_sample('napari', 'cells3d')

for layer in layers:
    layer.units = 'nm'
    layer.axis_labels = ['z', 'y', 'x']

viewer.scene.overlays.coordinate_grid.visible = True

Colorful names#

Another long-requested feature: displaying layer names on the canvas now has colormap-aware colors (#9598)! This comes with some fancy machinery to ensure that colors are shifted enough to be always readable.

import napari

viewer = napari.Viewer()
layers = viewer.open_sample('napari', 'lily')

for layer in layers:
    layer.name_overlay.visible = True

viewer.canvas.grid.enabled = True
viewer.canvas.grid.stride = 2

Cursor crosshair#

Ever use the grid mode for your multichannel data but then struggle to know where you’re clicking? Struggle no more! You can now enable the new crosshair overlay (#8017) to always locate your exact position in every viewbox.

Default dock area and tabify for plugin dock widgets#

Some plugin dock widgets are wider than they are tall, fitting poorly on the right-side dock and forcing users to manually move the widget to a different area every time on first launch. With #9526) and (#9707, you can now specify a default dock area and tabify behaviour for a dock widget contribution, which will prevent the need for this manual rearranging step:

  widgets:
    - command: example-plugin.my_widget
      display_name: My wide widget
      default_dock_area: bottom
      tabify: True

  • Remove PyQt5 support, part 1 (#9650)

Breaking Changes#

Dropped support for Qt5 backend#

We started warning about this in release v0.8.0; it is now time to fully drop support of Qt5! Qt5 has reached End Of Life on the 26th of May 2025. We migrated our bundle to Qt6 (PySide6) a year ago. #9650 is effectively removing PyQt5 support. PySide2 support was already removed in release 0.7.0, so we are now fully on Qt6!

Tidied up mouse callbacks#

Custom mouse callbacks can be defined via generators. Some quirks with this machinery have been smoothed out and some bugs fixed (#9513); this might cause some callbacks to no longer work as before. In principle, this should only affect callbacks that relied on buggy behavior, but please make sure to check if your old callbacks are still working, and open an issue on the napari repository if that’s not the case.

A notable change is that mouse_move callbacks previously did not work during drag, but now they do. If that’s not what you want, guard your callback with if not event.is_dragging!

Removed scale_bar.unit#

After deprecating it, we’re finally removing this field completely (#9218). Now the only way to set the unit on the scale bar is by setting units on the layers themselves!

Unified default font sizes#

We previously hardcoded default font sizes for all visuals in the canvas. Now (#8667, #9524), they respond to the global application settings (Preferences > Appearance > Font size) unless the font size is explicitly set for that specific model (by default it will be None).

So if you use the scale_bar, or Points.text or other layers and overlays that display text and you don’t like the new default, make sure to set your font size explicitly!

Key-bindings auto-repeat enabled by default#

With #9361, key-binding callbacks are now auto-repeated as everything else on your system. If your callbacks is a single-shot function, it will repeat when held; if it’s a generator, it will behave as before. The flag repeatable=True no longer has an effect.
